To access TDS design library, you will need to use <a className="tds-link tds-link--inline" href="https://www.figma.com/" target="_blank" rel="noopener noreferrer">Figma</a>. To take full advantage of it, a paid plan is needed (Professional / Organization / Enterprise) but basic functionality is usable also in a free plan.

## Install fonts

Make sure you have Lab Grotesque font installed. It can be purchased from the <a className="tds-link tds-link--inline" href="https://lettersfromsweden.se/font/lab-grotesque/" target="_blank" rel="noopener noreferrer">Letters from Sweden website</a>. TDS uses regular and bold weights.

If for some reason you don’t have access to the Lab Grotesque font, it may be substituted with Arial for basic prototyping needs. Keep in mind that any final UI designs going to production must use Lab Grotesque font.

## Components and styles

Use only the colour and text styles provided by TDS and do not create new ones in Figma.

TDS is currently in early beta and provides a limited set of components. While it’s not recommended to detach and modify instances, it may be done if absolutely needed. Keep in mind that some components (Accordion for example) provide a content slot which you can swap with your own content, removing the need to detach the whole component.

If you think some important styles or component features are missing or something is broken, please let us know at <a className="tds-link tds-link--inline" href="mailto:disain@tallinnlv.ee" target="_blank" rel="noopener noreferrer">{'disain' + '@' + 'tallinnlv.ee'}</a>
