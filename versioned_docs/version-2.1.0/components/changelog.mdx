## Version 2.1.0

### Typeface changed to Tallinn Sans

The design system now uses **Tallinn Sans**, the typeface made specifically for
Tallinn, in place of Lab Grotesque. Tallinn Sans is licensed for all employees
and partners of the city, so it no longer needs to be purchased separately.

**This changes how text is measured and will reflow layouts.** Tallinn Sans has
different metrics from Lab Grotesque, so line breaks, text widths and element
heights will shift. Check your pages after upgrading, particularly anywhere text
sits in a fixed-width or single-line container.

Regular, Italic, Bold and Bold Italic are all shipped. Previously only the
regular cut was declared, so bold and italic text was synthesised by the
browser; the real cuts are now used.

Sites that are not ready to move can stay on `tds-2.0.0.min.css`, which is
unchanged and still uses Lab Grotesque.
